# 해아림한의원 부평점 통합진료센터 (healim-clinic)

통증·추나요법·교통사고 후유증·만성 호흡기(보폐고)·맞춤 보약 로컬 특화 공식 홈페이지

## 📌 진료 과목
1. **척추·관절 통증 & 추나 클리닉** (/pain/): 목/허리 디스크, 오십견, 거북목, 퇴행성 관절염, 건강보험 추나요법 & 정밀 약침
2. **교통사고 후유증 클리닉** (/traffic-accident/): 자동차보험 100% 적용, 어혈 한약, 1:1 통원 집중 치료
3. **만성 기침·비염 호흡기 클리닉** (/respiratory/): 만성 잔기침, 비염/축농증, 후비루, 성대결절 점막 보습 '보폐고'
4. **맞춤 보약 & 공진단·경옥고** (/tonic/): 식약처 인증 정품 사향 공진단, 원방 경옥고, 수험생 총명탕, 기력회복
5. **의료진 & 진료시간** (/about/, /location/): 권형근 대표원장, 부평역 7번 출구 도보 5분, 월·수·금 20시 야간진료

## 💻 로컬 개발 & 빌드 명령어

```bash
# 의존성 설치
npm install

# 로컬 개발 서버 실행 (http://localhost:1313)
npm run dev

# 프로덕션 정적 파일 빌드 (./public)
npm run build
```
