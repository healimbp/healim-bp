# 해아림한의원 부평점 통합진료센터 (healim-clinic)

척추·관절 통증, 추나요법, 교통사고 후유증, 만성 호흡기(보폐고), 맞춤 보약 특화 통합진료센터 공식 웹사이트 & 자동화 퍼블리싱 시스템  
- **특화 서브 도메인**: `https://healim-bp.com`
- **본원(뇌신경정신) 대표 도메인**: `https://healimbp.com`

---

## 🌟 1. 6단계 심층 임상 칼럼 & 자동화 시스템 표준

모든 칼럼은 `healimbp.tistory.com/46` 표준에 100% 부합하도록 설계되었습니다.

### 📐 6대 심층 의학 콘텐츠 구조
1. **01. 해부학적·생리학적 발생 기전과 원인**: 신경/근막/관절 구조의 정밀 분석.
2. **02. 진행 단계별 중증도 및 30초 자가진단법**: 3단계(초기/중기/심화) 비교 분석 표 및 자가 진단 가이드.
3. **03. 한의학적 병리 진단 및 현대의학 매칭**: 동의보감 병리와 현대 해부학적 질환명 매칭.
4. **04. 3대 체질별 맞춤 변증 유형**: 급성 어혈염증형 / 만성 한습저체형 / 간신기혈허약형 맞춤 한약 처방 원리.
5. **05. 1:1 비수술 복합 치료 시스템**: 정밀 추나, 소염 약침, 봉약침, 맞춤 한약 치료.
6. **06. 진료실 자주 묻는 질문 (FAQ 3문 3답)**: 환자 주요 질문에 대한 전문의 명쾌한 카드형 Q&A.

## 🚀 2. 칼럼 생성 및 일일 4회 자동 발행 가이드

### ① 새 칼럼 생성 명령어
칼럼 생성 즉시 **6단계 심층 마크다운 템플릿**과 **1080x1080 고해상도 카드 썸네일(SVG/PNG)**이 자동 생성됩니다.

```bash
# [방법 A] 오늘 날짜 즉시 발행용 칼럼 생성
npm run new:column lumbar-disc-sciatica-chuna

# [방법 B] 특정 날짜 & 시간대 예약 발행 칼럼 생성 (예: 2026-09-16 2회차 13:00)
npm run new:column vocal-cord-nodules 2026-09-16 2
```

> **⏰ 일일 4회차 발행 시간표**:
> - **1회차**: 09:00 KST (척추·관절 통증 & 추나)
> - **2회차**: 13:00 KST (만성 기침/호흡기 & 보폐고)
> - **3회차**: 17:00 KST (교통사고 후유증 & 자동차보험)
> - **4회차**: 21:00 KST (맞춤 보약 & 체질 개선)

### ② GitHub 푸시를 통한 자동 발행 & 텔레그램 알림

```bash
git add .
git commit -m "feat: add new clinical columns"
git push origin main
```

- **GitHub Actions (`.github/workflows/deploy.yml`)**가 매일 **09:00, 13:00, 17:00, 21:00 KST**에 자동 작동합니다.
- 사이트(`https://healim-bp.com/`)가 자동 빌드 및 배포됩니다.
- 해당 시간대에 도래한 칼럼의 **1080x1080 카드 썸네일**과 **티스토리 46번 서식 HTML 파일**이 텔레그램(`@healim_clinic_bot`)으로 즉시 자동 전송됩니다.
- 전송받은 HTML 파일을 복사하여 티스토리 에디터에 붙여넣기만 하면 즉시 완벽한 레이아웃으로 발행됩니다.

## 🛠️ 3. 주요 스크립트 명령어

```bash
# 1. 로컬 개발 서버 실행 (http://localhost:1313)
npm run dev

# 2. 정적 사이트 빌드 (./public)
npm run build

# 3. 현재 시점 예약 칼럼 자동 발행 및 텔레그램 전송
npm run publish:slot

# 4. 모든 28개 칼럼 텔레그램 일괄 전송
npm run publish:all

# 5. 모든 칼럼의 1080x1080 고해상도 카드 썸네일 일괄 재생성
npm run thumbnails:build

# 6. 전체 칼럼 무결성 검증 (중복 불릿, FAQ 누수, 목차 검사)
npm run validate
```
